TL-ST1008F v2 — stock U-Boot can TFTP

Draft note for the OpenWrt maintainers.

Draft — openwrt/openwrt, not yet filed Verified on hardware

Hi — and thanks for the excellent work bringing OpenWrt up on this device. I found a way to TFTP the image over the SFP+ ports. The install doc (commit 39b9b491bb) currently says serial/ymodem only:

The stock U-boot has broken networking thus no TFTP available. Serial transfer only.

Recipe

rtk network on
rtk i2c write 8 1 0xfe
rtk i2c write 8 3 0
setenv ipaddr <switch-ip>
setenv serverip <tftp-ip>
tftpboot 0x84f00000 <initramfs-kernel.bin>
iminfo 0x84f00000
bootm 0x84f00000
rtk network onInits the SDK (MAC + SerDes); registers I2C dev 0–7 = SFP EEPROMs, dev 8 = TCA9534A @ 0x38. Ends Err:0xf030:FAIL = benign (PHY-less SerDes ports). Run once per boot.
rtk i2c write 8 1 0xfeExpander output latch. tx-disable active-high, pin N = cage N+1. 0xfe = cage 1 on, 2–8 off. (0xfd = cage 2.)
rtk i2c write 8 3 0Expander config reg → all pins output. Power-on default is all-input → lasers off. Write latch (reg 1) before direction (reg 3), or pins briefly drive low.
setenv ipaddr / serveripSwitch IP / TFTP server IP.
tftpboot 0x84f00000Load to DDR clear of U-Boot's relocated code/stack (ymodem path uses 0x82000000).
iminfo 0x84f00000Verify uImage header + CRC.
bootm 0x84f00000Boot standard-magic uImage (not the RTK boota).

Laser control

  • No native laser/cage command exists — the two rtk i2c write 8 lines are the only way.
  • Issue them after rtk network on — SDK init parks the expander all-off.

Verified

  • TFTP-booted the OpenWrt initramfs on two SFP+ cages, each with a generic FS 10GBASE-SR module — no vendor-SFP lock in U-Boot.
  • iminfo checksum OK; initramfs booted.
Light one cage only. Two cages + both lasers + rtk network on → broadcast storm. The OpenWrt initramfs lights every laser with no STP — unplug other fibres before bootm.

Lighting more cages / speeds — to confirm on-device

  • All lasers on: rtk i2c write 8 1 0x00 — safe with only one fibre connected (no loop).
  • Multiple cages without a storm: rtk port-isolation on isolates the front ports (found in the loader) — likely prevents the front↔front forwarding storm. No STP in stock U-Boot (minimal loader).
  • Per-port speed: rtk 10g <port> fiber10g | fiber1g sets SerDes media (fiber100m is in help but not dispatched).
